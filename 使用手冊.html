1. 快速開始

  1. 把收到的壓縮檔整個解壓縮到任意位置（例如 D:\ebook-reader-portable）。不要在壓縮檔裡直接執行。
  2. 雙擊資料夾中的 start.bat。會出現一個黑色命令視窗，接著瀏覽器自動開啟書庫頁面。
  3. 第一次使用時書庫是空的，會自動跳出「資料夾設定」，貼上你放電子書的資料夾路徑，按「新增並掃描」。
  4. 點書的封面就能開始閱讀。
黑色命令視窗就是程式本體：閱讀期間請保留它（可以縮到最小）。要結束程式時直接關掉這個視窗。
瀏覽器若沒有自動開啟，請手動開瀏覽器並輸入 http://127.0.0.1:8000/。

支援格式：EPUB、KEPUB（Kobo 格式）、PDF、TXT。

2. 書庫

書庫以封面方格列出所有書籍，每本書的卡片顯示檔名、書名／作者、所在資料夾、閱讀狀態與進度條。

功能說明
搜尋輸入關鍵字，可比對檔名、書名、作者、資料夾名稱，邊打邊篩選。
格式篩選只顯示 EPUB、PDF 或 TXT。
閱讀狀態「已閱讀」只顯示標記為閱讀完畢的書；「尚未閱讀」顯示其餘的書。
排序最近閱讀、檔名、書名、加入時間、閱讀進度。
標籤列搜尋列下方會列出所有用過的標籤，點一下只顯示該標籤的書，點「全部」取消。

格式、閱讀狀態與排序的選擇會被記住，下次開啟維持相同設定。

3. 加入書籍

方法一：設定掃描資料夾（建議）

  1. 按右上角「資料夾設定」。
  2. 貼上資料夾路徑，例如 D:\電子書，按「新增並掃描」。子資料夾裡的書也會一併加入。
  3. 之後在資料夾裡新增或刪除書籍，按「重新掃描」即可更新書庫。每次啟動程式時也會自動掃描一次。

可以設定多個資料夾。在資料夾設定中按某個資料夾旁的「移除」，就不再掃描它（原始檔案不會被刪除）。

取得資料夾路徑的方法：在檔案總管開啟該資料夾，點上方網址列，路徑會反白，按 Ctrl+C 複製。

方法二：上傳

按「上傳」選擇檔案（可一次選多個）。上傳的書會複製一份到程式資料夾的 books\ 中，原檔可以刪掉或搬走。

4. 整理書籍

按鈕說明
完讀標記這本書已閱讀完畢，卡片會顯示「✅ 閱讀完畢」；再按「取消完讀」可取消。
標籤為書加上自訂分類，多個標籤用逗號分隔，例如 小說, 推理。清空後儲存即移除所有標籤。
移除從書庫移除這本書。
・掃描資料夾中的書：只是不再顯示，原始檔案不會被刪除，重新掃描也不會再出現。
・用「上傳」加入的書：會連同 books\ 裡的副本一起刪除。

「閱讀完畢」本身也是一個標籤，所以標籤列也能用它篩選。卡片上的「已讀 xx%」是自動記錄的閱讀進度，與「完讀」標記無關。

5. 閱讀

點封面進入閱讀頁。程式會自動記住讀到哪裡，下次開啟同一本書時從上次的位置繼續。

上方工具列

項目說明
← 書庫回到書庫。
目錄（EPUB）下拉選單選擇章節直接跳過去。書本身沒有目錄時不顯示。
頁碼選單（PDF）下拉選擇任一頁直接跳過去。
翻頁方向切換「向右翻頁 →」或「← 向左翻頁」。直排的中文書通常是向左翻。每本書各自記住。
A− / A＋EPUB、TXT 調整字級；PDF 調整頁面縮放。
空白− / 空白＋EPUB、TXT 調整左右留白，讓文字往中間集中，寬螢幕閱讀較舒適。
百分比整本書的閱讀進度。EPUB 第一次開啟時需要計算一下才會出現。

畫面其他資訊

  • 目前章節：顯示在工具列下方（書有目錄或書籤時才有）。
  • 頁碼：顯示在畫面底部。EPUB 顯示的是「本章」的第幾頁／共幾頁；PDF 是實際頁碼；TXT 以一個畫面為一頁。
  • 翻頁：點畫面左右兩側的 ‹ › 按鈕，或使用鍵盤（見下節）。

6. 鍵盤操作

按鍵動作
→ / ←往右／往左翻頁（實際是上一頁或下一頁，依「翻頁方向」設定而定）
PageDown、空白鍵下一頁（固定，不受翻頁方向影響）
PageUp上一頁（固定）

TXT 是上下捲動閱讀，也可以直接用滑鼠滾輪。

7. 資料保存與搬移

所有資料都存在程式資料夾內，不會寫到電腦的其他地方：

位置內容
data\書庫清單、閱讀進度、標籤、封面縮圖。
books\用「上傳」加入的書。
  • 搬到別台電腦：把整個程式資料夾複製過去即可，閱讀進度與標籤都會保留。掃描資料夾的路徑若在新電腦上不同，請到「資料夾設定」重新設定。
  • 備份：複製 data\ 與 books\ 兩個資料夾。
  • 重設書庫：關閉程式後刪除 data\ 資料夾，下次啟動即為全新書庫（不影響電子書原始檔）。
  • 字級、留白、翻頁方向等閱讀偏好存在瀏覽器中，換瀏覽器或清除瀏覽資料後會恢復預設值。

8. 常見問題

雙擊 start.bat 後視窗一閃就關掉，或出現錯誤

確認已經完整解壓縮，且 start.bat 旁邊有 python、static 資料夾與 app.py。路徑太深時可能出錯，建議放在磁碟根目錄附近，例如 D:\ebook-reader-portable。

防毒軟體或 Windows 跳出警告

本程式不含自製的執行檔。start.bat 啟動的是 Python 官方發行、具 Python Software Foundation 數位簽章的 python\python.exe。若 Windows 出現「已保護您的電腦」，按「其他資訊」→「仍要執行」。若下載的壓縮檔被標記為來自網路，可在壓縮檔上按右鍵 →「內容」→ 勾選「解除封鎖」後再解壓縮。

出現「address already in use」或 8000 埠被占用

可能是程式已經開著（找找工作列上的黑色視窗），或其他程式占用了 8000 埠。可改用其他埠：在程式資料夾的網址列輸入 cmd 按 Enter，再執行 start.bat --port 8001，並用瀏覽器開 http://127.0.0.1:8001/。

想用手機或平板閱讀電腦上的書

同上方法開啟命令列，執行 start.bat --host 0.0.0.0，再用同一個網路下的手機瀏覽器開 http://電腦的IP:8000/（電腦 IP 可在命令列輸入 ipconfig 查詢）。Windows 防火牆可能會詢問是否允許，選擇允許私人網路。

TXT 檔開啟後是亂碼

程式會自動嘗試 UTF-8、繁體（Big5）、簡體（GB18030）、UTF-16 編碼。若仍是亂碼，請用記事本開啟該檔，「另存新檔」時編碼選「UTF-8」再重新掃描。

書庫找不到某本書

  • 確認副檔名是 .epub、.kepub、.pdf 或 .txt。
  • 書放進資料夾後要按「重新掃描」。
  • 若曾經按過「移除」，該書會被隱藏，重新掃描也不會出現；可把檔案改名後再掃描，或用「上傳」加入。

EPUB 的頁碼為什麼只算本章

EPUB 會依視窗大小與字級即時排版，要算出整本書的總頁數必須把每一章都排過一次，太費時，所以底部只顯示本章頁碼；整本書的進度請看工具列右側的百分比。
